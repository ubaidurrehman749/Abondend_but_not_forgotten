# Fact-Check Log

## Project: Abandoned but Not Forgotten

**Purpose:**  
This document tracks the accuracy of historical and scientific information presented in the project. It helps ensure that information about NASA missions, spacecraft, rovers, and space exploration is supported by reliable sources.

## Verification Guidelines

- Use official NASA websites and mission archives as primary sources.
- Cross-check mission dates, locations, objectives, and scientific achievements.
- Verify spacecraft and rover names and their mission details.
- Include the original source link for every verified fact.
- Mark information as pending if it has not yet been confirmed.
- Correct inaccurate or outdated information before project submission.
