# Quality Assurance (QA) Checklist

## Project: Abandoned but Not Forgotten

**Purpose:**

This checklist is used to review and test the project website to ensure that its features work correctly, information is displayed properly, and the website provides a good user experience across different devices.

## 1. Website Functionality

- [ ] Website loads without errors.
- [ ] Navigation links work correctly.
- [ ] Buttons perform their intended actions.
- [ ] Internal links navigate to the correct pages or sections.
- [ ] External links open the correct resources.
- [ ] No broken links or missing pages.

## 2. Content and Information

- [ ] Mission names are displayed correctly.
- [ ] Historical information is reviewed for accuracy.
- [ ] Mission dates and locations are checked.
- [ ] Text is readable and free from spelling mistakes.
- [ ] Images match their respective missions or spacecraft.
- [ ] Information sources and credits are included.

## 3. Images and 3D Models

- [ ] Images load correctly.
- [ ] Images are displayed in the correct proportions.
- [ ] 3D models load without errors.
- [ ] 3D models display the correct spacecraft or rover.
- [ ] Model interactions work as expected.
- [ ] Missing models or assets are identified.

## 4. Responsive Design

- [ ] Website displays correctly on desktop screens.
- [ ] Website displays correctly on tablets.
- [ ] Website displays correctly on mobile devices.
- [ ] Text and images fit different screen sizes.
- [ ] No unwanted horizontal scrolling.
- [ ] Navigation remains usable on smaller screens.

## 5. User Interface and Accessibility

- [ ] Text has sufficient contrast with the background.
- [ ] Font sizes are readable.
- [ ] Buttons and interactive elements are easy to identify.
- [ ] Images have appropriate alternative text.
- [ ] Keyboard navigation is checked.
- [ ] Page layout is consistent throughout the website.

## 6. Performance and Technical Review

- [ ] Website loads within a reasonable time.
- [ ] No major errors appear in the browser console.
- [ ] Images and other assets load correctly.
- [ ] No unnecessary duplicate content or broken components.
- [ ] Production build completes successfully.
